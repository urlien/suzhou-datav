# 参考案例 / Open Source References

本目录收录项目开发过程中参考的开源工具和案例。

## sc-datav

- **仓库：** [knight-L/sc-datav](https://github.com/knight-L/sc-datav)
- **作者：** knight-L
- **许可：** MIT
- **用途：** Three.js 3D地图 + 热力图可视化，本项目的核心参考
- **在线预览：** https://knight-l.github.io/sc-datav/#/demo1（需梯子）

> 如需查看或使用 sc-datav 源码，请直接访问上方仓库链接，或 clone 到本地：
> ```bash
> git clone https://github.com/urlien/sc-datav.git
> ```
